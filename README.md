# khalit7.github.io

Source for my personal site at **[khalit7.github.io](https://khalit7.github.io/)** — work,
selected projects, and how to reach me.

A single hand-written `index.html`: no framework, no build step, no external CSS, fonts or
trackers. Styles live in one `<style>` block and adapt to light and dark themes. The only
third-party requests are the YouTube project demos, embedded through `youtube-nocookie.com`.

```
index.html   the whole site
images/      profile photo and project screenshots
```

To work on it, open `index.html` in a browser. GitHub Pages serves `main` from the repository
root, so a push to `main` deploys.
